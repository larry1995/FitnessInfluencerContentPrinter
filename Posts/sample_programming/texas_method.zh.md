# 🏋️ 德州训练法 (Texas Method) — 最佳进阶力量举训练计划（免费）

新手线性递进已经到头了？你不能再每次训练都加重了？欢迎来到进阶训练。德州训练法 (Texas Method) 是处于这个阶段的举重者最经过验证的训练框架之一。

为什么德州训练法有效：
与其每次训练都加重（这在4-8个月后就不管用了），德州训练法采用每周递进，三个不同的训练日在一周内调控训练量、恢复和强度。

训练结构 — 每周3天：

📅 周一 — 容量日
最难的一天。大训练量驱动适应。

深蹲 (Squat)：5 x 5 @ 周五5RM的90%
卧推 (Bench Press)（或每周交替站姿推举 OHP）：5 x 5 @ 周五5RM的90%
硬拉 (Deadlift)：1 x 5 @ 当前5RM的90%（硬拉不需要5x5）
杠铃划船 (Barbell Row)：3 x 8
辅助动作：双杠臂屈伸 (Dips) 或窄握卧推 (Close-Grip Bench) 3 x 8-10

📅 周三 — 恢复日
轻松简单。促进恢复而不增加疲劳。

深蹲 (Squat)：2 x 5 @ 周一重量的80%
站姿推举 (OHP)（或卧推 Bench，交替）：3 x 5 @ 轻/中等重量
引体向上 (Pull-ups)：3 x 自重力竭
背部伸展 (Back Extensions) 或 GHR：3 x 10
腹部训练：3 x 15

📅 周五 — 强度日
破纪录的日子。用新的个人纪录挑战自己。

深蹲 (Squat)：1 x 5（新5RM——比上周五加5磅）
卧推 (Bench Press)（或站姿推举 OHP）：1 x 5（新5RM——加5磅）
硬拉 (Deadlift)：1 x 5（新5RM——加5-10磅）
翻举 (Power Cleans)：5 x 3（可选——如果你更愿意，可以用负重引体替代）

每周递进：
- 每周深蹲和卧推的周五PR加5磅
- 每周硬拉的周五PR加5-10磅
- 周一的容量自动调整（新的周五PR的90%）
- 预计在停滞之前可以持续2-4个月的每周PR

现代改良版（基于RPE）：
原版德州训练法使用固定百分比。现代教练加入了RPE进行自我调节：
- 容量日：5组5次中第5组RPE 7-8
- 恢复日：RPE 5-6
- 强度日：单组最大重量RPE 9-9.5

这样可以在状态差的日子避免过度消耗，同时在状态好的日子仍然全力以赴。

停滞时怎么办：
如果连续2周无法完成周五的PR：
**1. 周五的重量回退5-10%**
**2. 以更小的幅度（2.5磅）重新递增**
**3. 如果再次停滞，将周五改为三次一组（1 x 3）代替五次**
**4. 4-6个月后，考虑转向分阶段周期化训练计划**

进阶增长的营养需求：
- 蛋白质：每磅体重0.8-1.0g
- 热量：略有盈余（+200-500千卡）以获得最佳力量增长
- 睡眠：8小时以上——进阶训练比新手训练要求更高
- 肌酸：每天5g

**总结：**
德州训练法比几乎任何其他计划创造了更多的进阶PR。它简单，免费，而且有效。秘密不在于计划本身——而在于连续数月坚持执行、吃够、睡够。
