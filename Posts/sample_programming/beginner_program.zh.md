# 🏋️ 最佳新手力量举训练计划（12周，免费）

刚接触力量举？别再频繁换计划了。这是一个为期12周的线性递进训练计划，真正有效——有科学研究支持，我们健身房已有数百名学员验证过。

为什么线性递进对新手有效：
2017年一项针对新手力量训练的荟萃分析发现，在训练的前6-12个月中，简单的线性模型与复杂的周期化训练产生了相同的力量增长效果。翻译一下：你现在还不需要复杂的训练计划，你需要的是一致性和渐进超负荷。

训练结构 — 每周3天：

📅 A日 — 深蹲日
A1. 深蹲 (Back Squat) — 3 x 5（每次训练加5磅）
A2. 卧推 (Bench Press) — 3 x 5（每次训练加5磅）
A3. 杠铃划船 (Barbell Row) — 3 x 5（每次训练加5磅）
B1. 腿举 (Leg Press) — 3 x 10
B2. 哑铃飞鸟 (Dumbbell Chest Flyes) — 3 x 12

📅 B日 — 硬拉日
A1. 硬拉 (Deadlift) — 1 x 5（每次训练加10磅）
A2. 站姿推举 (Overhead Press) — 3 x 5（每次训练加5磅）
A3. 引体向上或高位下拉 (Pull-ups or Lat Pulldown) — 3 x 8
B1. 罗马尼亚硬拉 (Romanian Deadlift) — 3 x 8
B2. 面拉 (Face Pulls) — 3 x 15

📅 每周轮换：
第1周：A / B / A
第2周：B / A / B
第3周：A / B / A（循环重复）

起始重量：
每个动作从你估算的1RM的50%开始。如果你不知道自己的极限重量，就从一个你可以做3组5次、还留有2-3次余量的重量开始。重量很快就会变重。

何时减载：
如果连续2次训练中某个动作无法完成所有组数和次数：
**1. 将该动作的重量降低10%**
**2. 从降低后的重量继续加重**
**3. 如果停滞3次，说明该转向进阶计划了**

进度时间线：
- 第1-4周：重量感觉轻松。相信过程。
- 第5-8周：重量开始有挑战。动作质量始终是第一优先。
- 第9-12周：每一次都在拼。这才是力量增长的阶段。

男性新手在12周内深蹲通常可以增长60-90磅。女性通常增长30-50磅。这些都是来自我们教练经验的真实、可达到的数字。

营养最低要求：
- 蛋白质：每磅体重0.7-1.0g，每天
- 热量：维持量或略有盈余（+200-300千卡）
- 睡眠：每晚7-9小时

**总结：**
简单就是有效的。2023年一项系统综述发现，未经训练的个体从任何渐进式抗阻训练计划中都能获得显著的力量增长——关键变量是一致性，而不是复杂性。从这里开始，按照计划执行，12周内不要换计划。
