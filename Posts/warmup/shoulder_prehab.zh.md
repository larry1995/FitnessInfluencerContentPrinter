# 🏋️ 打造铁壁肩膀 — 每个举重者都需要的5个预防性训练动作

肩部伤害是抗阻训练中排名第一的过度使用损伤。一项针对业余举重者的研究发现，36%的人报告了当前或近期的肩部疼痛——大多来自卧推和过头推举。

解决方法不是避免推举。而是在你的肩膀出问题之前，先强化那些保护肩膀的稳定肌。

以下是5个有肌电图和临床研究支持的练习：

1️⃣ 弹力带扩胸 (Band Pull-Aparts)
目标肌群：后三角肌、中/下斜方肌、菱形肌
为什么：这些肌肉平衡了大多数训练计划中占主导地位的重推举。这些肌肉薄弱会导致肩膀前倾，造成肩峰撞击。
怎么做：双手握住轻阻力弹力带，手臂伸直在前方。将弹力带拉开直到触碰胸部。挤压肩胛骨。3 x 15-20次。
何时做：在每一组推举热身组之间。没错——每一组都做。

2️⃣ 面拉加外旋 (Face Pulls with External Rotation)
目标肌群：后三角肌、冈下肌、小圆肌、下斜方肌
为什么：Reinold等人（2009）的肌电图研究发现，将拉的动作与外旋结合的练习，在常见的肩部康复练习中对旋转袖和肩胛稳定肌产生了最高的综合激活。
怎么做：绳索调至面部高度。拉向前额，然后向外旋转双手，使手臂形成"双头肌展示"的姿势。3 x 15-20次。
关键提示：用后三角肌启动，不是二头肌。最后的旋转是最重要的部分。

3️⃣ 侧卧外旋 (Side-Lying External Rotation)
目标肌群：冈下肌、小圆肌（在推举时对肩部稳定性最负责的两块旋转袖肌肉）
为什么：对外旋肌的孤立训练对于内旋肌（胸大肌、背阔肌、前三角肌）显著更强的举重者至关重要——这几乎是每个力量举运动员的情况。
怎么做：侧卧，上臂贴着肋骨，肘部成90度。缓慢且有控制地向上旋转一个轻哑铃（3-8磅）。每侧3 x 12-15次。
关键提示：保持肘部紧贴体侧。如果肘部抬起来了，说明重量太重了。

4️⃣ 肩胛墙上滑行 (Scapular Wall Slides)
目标肌群：下斜方肌、前锯肌
为什么：这些肌肉控制肩胛骨的上回旋——过头推举时你的肩胛骨必须完成的动作。不良的肩胛控制 = 在负重下发生撞击。
怎么做：背部、头部和手臂靠墙站立。保持墙面接触，将手臂向上滑至头顶再滑回。3 x 10-12次。
关键提示：如果你的下背离开了墙面，说明你的活动度还不够——只抬到能保持背部贴墙的高度。

5️⃣ 俯卧Y-T-W上举 (Prone Y-T-W Raises)
目标肌群：下斜方肌(Y)、中斜方肌(T)、旋转袖(W)
为什么：这三个位置综合激活了整个后侧肩带。2015年一项系统综述将这些动作列为肩胛肌激活最有效的练习之一。
怎么做：面朝下俯卧在30-45度的斜板上。用轻哑铃（2-5磅）或不用重量：
Y — 手臂以45度角向头顶伸展，拇指朝上。8-10次。
T — 手臂直接向两侧伸展，拇指朝上。8-10次。
W — 手肘弯曲，挤压肩胛骨，外旋。8-10次。
完整做1-2轮三个位置。

预防性训练方案（10分钟，每周3次）：
**1. 弹力带扩胸 (Band Pull-Aparts)：2 x 20**
**2. 面拉加外旋 (Face Pulls w/ External Rotation)：2 x 15**
**3. 侧卧外旋 (Side-Lying External Rotation)：每侧2 x 12**
**4. 肩胛墙上滑行 (Scapular Wall Slides)：2 x 10**
**5. 俯卧Y-T-W (Prone Y-T-W)：完整做1轮**

何时做：
- 推举训练前（作为热身的一部分）
- 休息日（作为恢复训练）
- 推举训练后（作为放松）
- 任何时候肩膀感觉"嘎嘎作响"或紧绷

**总结：**
你不会不热身髋关节就去做大重量深蹲。别不准备肩膀就去做大重量推举了。每周3次、每次10分钟的预防性训练，可以防止那个让你缺席数月的肩部伤害。预防永远比治疗便宜。
