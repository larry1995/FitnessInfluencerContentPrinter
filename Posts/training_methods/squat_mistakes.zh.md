# 🏋️ 毁掉你深蹲的5个错误

Chad Wesley Smith 和 Marisa Inda 详细分析了从初学者到有经验的训练者中最常见的深蹲 (Squat) 错误。

1️⃣ 下蹲时失控下落
快速下落感觉很猛，但你会在底部失去张力然后被压住。
纠正方法：控制下降过程。掌控每一寸行程。想着"慢下来，向两侧撑开"。

2️⃣ 膝盖内扣
膝外翻会削弱蹲起时的力量输出，并增加膝盖受伤风险。
纠正方法：把膝盖推向脚尖方向。用"脚掌撑开地面"来提示自己。

3️⃣ 上身前倾
如果杠铃重心前移，你的深蹲就变成了早安式体前屈。
纠正方法：用力撑紧核心。"挺胸，深吸气。"全程保持上背部收紧。

4️⃣ 站距宽度不对
每个人的深蹲站距因身体结构而异。照搬别人的站距是行不通的。
纠正方法：多尝试。双脚应该站在让髋关节感觉最打开、能舒适蹲到足够深度的位置。

5️⃣ 核心支撑不到位
吸气到胸腔而不是腹部 = 没有核心稳定性。
纠正方法：深吸一口气到腹部。向外顶住腰带（或者想象腰带在的位置）。整个动作过程中保持这个状态。

深蹲日训练示例：
A1. 后蹲 (Back Squat) — 4 x 5 @ RPE 7-8（注意核心支撑和膝盖轨迹）
A2. 停顿深蹲 (Pause Squat) — 3 x 3 @ 75%（在底部停顿3秒）
B1. 保加利亚分腿蹲 (Bulgarian Split Squat) — 3 x 8 每侧
B2. 腿举 (Leg Press) — 3 x 10-12（脚放高放宽侧重臀部发力）
C1. 罗马尼亚硬拉 (Romanian Deadlift) — 3 x 8-10
C2. 腿弯举 (Leg Curl) — 3 x 12-15
D1. 健腹轮 (Ab Wheel Rollouts) — 3 x 10（核心支撑练习）

🔑 规律总结：
大多数深蹲问题都源于失去张力。从出杠到回杠，全程保持紧绷。
