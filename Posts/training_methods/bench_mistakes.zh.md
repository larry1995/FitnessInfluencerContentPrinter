# 🏋️ 毁掉你卧推的5个错误

Chad Wesley Smith 和 Marisa Inda（Juggernaut Training Systems）详细分析了最常见的卧推 (Bench Press) 错误——以及如何纠正它们。

1️⃣ 握距错误
太宽 = 肩膀压力过大。太窄 = 锁定无力。
纠正方法：无名指对准杠铃上的刻线是一个不错的起点，然后根据自己的体型进行微调。

2️⃣ 没有腿部驱动
你的卧推从脚下开始发力。脚掌平放但没有张力 = 浪费重量。
纠正方法：双脚用力蹬地。想象"把自己从杠铃下推开"。

3️⃣ 手肘外展过大
手肘90°外展会让肩膀处于非常糟糕的位置。
纠正方法：下放时手肘收至约45°，推起时让手肘自然外展。

4️⃣ 失去背弓
合理的背弓并不危险——它能缩短运动行程并保护肩膀。
纠正方法：在取杆之前设好背弓。肩胛骨向后并向下收紧。

5️⃣ 杠铃路径错误
杠铃不应该垂直上下运动，而应该沿着一条轻微的J形曲线移动。
纠正方法：触胸点在乳头线下方，向脸部方向斜推至肩膀正上方锁定。

卧推日训练示例：
A1. 卧推 (Bench Press) — 4 x 5 @ RPE 7-8（注意握距、背弓、杠铃路径）
A2. 停顿卧推 (Paused Bench Press) — 3 x 3 @ 80%（停顿2秒，消除反弹）
B1. 哑铃上斜卧推 (Dumbbell Incline Press) — 3 x 8-10（控制离心阶段）
B2. 绳索飞鸟 (Cable Flyes) — 3 x 12-15（底部充分拉伸）
C1. 三头肌下压 (Tricep Pushdowns) — 3 x 12-15
C2. 面拉 (Face Pulls) — 3 x 15-20（肩膀健康）
